One line roasting my own AI agent: it needed a 17 MB CLI, a repo, a transcript bundle, and a signed Solana message to write one line — then asked me to proofread it.

## Run it

```sh
node main.ts
```

The program writes a single line of at most 200 characters to `/output/entry.txt`.
